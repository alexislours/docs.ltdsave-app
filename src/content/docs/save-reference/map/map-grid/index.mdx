## Fields

### `UnlockAreaGroup`

<LeafMeta name="UnlockAreaGroup" leaves={frontmatter.leaves} />

Declared in the map schema as a fixed-size `UInt64Array` of 4 elements, but never read or written by the game. Always `[0, 0, 0, 0]` in normal gameplay.
Likely a leftover from an earlier per-level area-group system that was replaced by [`Player.UnlockMapLevel`](../../player/player/#unlockmaplevel).
