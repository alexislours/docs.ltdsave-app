### `Currency`

<LeafMeta name="Currency" leaves={frontmatter.leaves} />

The currency displayed in the game. In normal gameplay, directly tied to the [Region](#region) selected at the start of the game.

| `Player.Region` | Available `Player.Currency` values                           |
| --------------- | ------------------------------------------------------------ |
| `Japan`         | `Yen`, forced                                                |
| `Europe`        | `Euro` **or** `Pound`                                        |
| `NorthAmerica`  | `Dollar` **or** `Peso`                                       |
| `SouthAmericaN` | `Dollar` **or** `Peso`                                       |
| `SouthAmericaS` | `Dollar` **or** `Peso`                                       |
| `Australia`     | `Dollar`, forced                                             |
| `Asia`          | `AsiaDollar` **or** `Won`                                    |
| `OthersN`       | one of `Yen`, `AsiaDollar`, `Euro`, `Dollar`, no user choice |
| `OthersS`       | one of `Yen`, `AsiaDollar`, `Euro`, `Dollar`, no user choice |

For the `OthersN` and `OthersS` regions, the game automatically picks the currency based on the following logic:

```d2 title="OthersN/OthersS currency flowchart" width=300

start: "Region = OthersN or OthersS"
call: "nn::time::GetDeviceLocationName()"

a: "region == Asia\nAND city == Tokyo" {shape: diamond}
b: "region == Asia" {shape: diamond}
c: "region == Europe" {shape: diamond}
d: "region == Australia" {shape: diamond}

yen: "Yen"
asiaDollar: "AsiaDollar"
euro: "Euro"
dollar: "Dollar"

start -> call
call -> a
a -> yen: "yes"
a -> b: "no"
b -> asiaDollar: "yes"
b -> c: "no"
c -> euro: "yes"
c -> d: "no"
d -> dollar: "yes"
d -> dollar: "no"
```
