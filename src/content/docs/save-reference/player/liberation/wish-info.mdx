The profile's **fountain wish** list, stored as three parallel arrays keyed by slot: [`WishIdValue`](#wishidvalue) names the wish in each slot, while [`IsLiberated`](#isliberated) and [`IsNew`](#isnew) flag whether that wish has been unlocked and whether it is newly added and unseen.

## Fields

### `IsLiberated`

<LeafMeta name="IsLiberated" leaves={frontmatter.leaves} />

Parallel boolean array marking which registered fountain wishes have been **liberated** (unlocked). Each slot lines up with [`WishIdValue`](#wishidvalue) (which wish) and [`IsNew`](#isnew).

### `IsNew`

<LeafMeta name="IsNew" leaves={frontmatter.leaves} />

Parallel boolean array marking which registered fountain wishes are **new**: recently added to the list and not yet viewed by the player (it backs the "NEW!" indicator).

### `WishIdValue`

<LeafMeta name="WishIdValue" leaves={frontmatter.leaves} />

The list of fountain wishes the profile has registered: each entry identifies one wish, stored as the `murmur3_x86_32` hash of a `FountainWishListData` row (the game's wish catalog). Entries are sorted ascending with any unused tail zero-padded (`0` marks an empty slot), and slot `i` is the join key naming the wish that slot `i` of the parallel [`IsLiberated`](#isliberated) and [`IsNew`](#isnew) arrays describes.
