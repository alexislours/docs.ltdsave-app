### `CurrentPlayDay`

<LeafMeta name="CurrentPlayDay" leaves={frontmatter.leaves} />

The day-of-month component of the calendar date the `DailyLog` block currently belongs to. When the daily counters are rolled over, the game stamps the date from the console clock into the triplet `CurrentPlayYear` / `CurrentPlayMonth` / `CurrentPlayDay`. The game compares it against the current date to detect a day change and reset the daily counters.

<Bounds>
  <Fragment slot="ingame">`1`..`31`, the day of the month.</Fragment>
  <Fragment slot="accepted">any `UInt32`</Fragment>
</Bounds>

### `CurrentPlayMonth`

<LeafMeta name="CurrentPlayMonth" leaves={frontmatter.leaves} />

The calendar-month component of the date the `DailyLog` block currently belongs to. When the daily counters roll over, the game stamps the console clock's date into the triplet `CurrentPlayYear` / `CurrentPlayMonth` / `CurrentPlayDay`, and compares it against the current date to detect a day change and reset the daily counters.

<Bounds>
  <Fragment slot="ingame">
    `1`..`12`, the month (`1` = January … `12` = December). and `CurrentPlayYear`.
  </Fragment>
  <Fragment slot="accepted">any `UInt32`</Fragment>
</Bounds>

### `CurrentPlayYear`

<LeafMeta name="CurrentPlayYear" leaves={frontmatter.leaves} />

The calendar year of the date the `DailyLog` block currently belongs to. When the daily counters roll over, the game stamps the console clock's date into the triplet `CurrentPlayYear` / `CurrentPlayMonth` / `CurrentPlayDay`, and compares it against the current date to detect a day change and reset the daily counters.

<Bounds>
  <Fragment slot="ingame">the four-digit system year at the time of play (e.g. `2026`)</Fragment>
  <Fragment slot="accepted">any `UInt32`</Fragment>
</Bounds>

### `CurrentSumDay`

<LeafMeta name="CurrentSumDay" leaves={frontmatter.leaves} />

The `DailyLog`'s date as a single day number: days since `1970-01-01` for the same date as the `CurrentPlayYear` / `CurrentPlayMonth` / `CurrentPlayDay` triplet (e.g. `20581` = `2026-05-08`).
